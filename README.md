# AI Student Assistant

## Project Description
AI Student Assistant is a chatbot designed to help students with basic educational questions.

## Features
- Answers Python-related questions
- Explains Artificial Intelligence
- Provides basic Science and Computer knowledge
- Helps students with study-related questions

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- FLAN-T5 Small Model

## How It Works
The chatbot first checks its knowledge dictionary.
If the question is not available, it uses the AI model to generate an answer.
